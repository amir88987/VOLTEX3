# VOLTEX

برنامه اندروید برای دانلود ویدیوی یوتیوب با چند کیفیت. بدون سرور؛ همه‌چیز روی خود گوشی انجام می‌شود.

- رابط فارسی و راست‌چین، تیره
- لینک را بچسبان یا از برنامه یوتیوب با «اشتراک‌گذاری» بفرست
- کیفیت‌ها از ۱۴۴p تا ۱۰۸۰p (اگر موجود باشد) و «فقط صدا»
- کیفیت‌های بالا تصویر و صدا را جدا می‌گیرند و روی گوشی با MediaMuxer ترکیب می‌کنند
- دانلود در پس‌زمینه با نوتیفیکیشن و دکمه لغو
- ذخیره در `Movies/VOLTEX` و `Music/VOLTEX`

اندروید ۸ به بالا.

---

## راه ۱: ساخت APK بدون نصب هیچ‌چیز (GitHub Actions) — پیشنهادی

1. در github.com حساب رایگان بساز و یک مخزن (Repository) جدید بساز، مثلاً `videogir`.
2. همه فایل‌های این پوشه را (از جمله پوشه مخفی `.github`) در مخزن آپلود کن.
   - روی سایت: Add file ← Upload files. حواست باشد پوشه `.github` هم آپلود شود.
3. به تب **Actions** برو. اگر پرسید، ورک‌فلو را فعال کن. **Build APK** را انتخاب کن و **Run workflow** را بزن.
4. بعد از حدود ۵ تا ۱۰ دقیقه، داخل همان اجرا بخش **Artifacts** فایل `VOLTEX-apk` را می‌بینی. دانلودش کن، zip را باز کن و `VOLTEX.apk` را روی گوشی نصب کن.

### لینک دانلود ثابت برای سایتت
در مخزن بخش **Releases ← Create a new release** برو، یک تگ مثل `v1.0` بساز و منتشر کن (یا از ترمینال: `git tag v1.0 && git push --tags`).
ورک‌فلو خودش APK را به آن Release اضافه می‌کند و لینک ثابت این می‌شود:

```
https://github.com/USERNAME/videogir/releases/latest/download/VOLTEX.apk
```

این لینک را در سایتت بگذار. یا فایل را دانلود کن و روی هاست خودت آپلود کنی.

## راه ۲: ساخت با Android Studio

1. Android Studio را نصب کن، **Open** ← این پوشه.
2. صبر کن Gradle همگام‌سازی شود (بار اول چند دقیقه طول می‌کشد).
3. منوی **Build ← Build APK(s)**. خروجی در `app/build/outputs/apk/release/` است.

## نصب روی گوشی
فایل APK را به گوشی منتقل کن و باز کن. اگر پرسید، «نصب از منابع ناشناس» را برای همان برنامه (مرورگر یا مدیر فایل) فعال کن.

## امضای اختصاصی (برای انتشار روی سایت، یک‌بار انجام بده)
APK پیش‌فرض با کلید debug امضا می‌شود. برای نصب و استفاده شخصی کافی است ولی برای انتشار بهتر است کلید خودت را بسازی و **همیشه نگهش داری**، چون آپدیت‌های بعدی باید با همان کلید امضا شوند:

```
keytool -genkeypair -v -keystore release.jks -alias videogir -keyalg RSA -keysize 2048 -validity 10000
```

سپس کنار پروژه فایل `keystore.properties` بساز:

```
storeFile=release.jks
storePassword=رمز-تو
keyAlias=videogir
keyPassword=رمز-تو
```

برای GitHub Actions: فایل jks را base64 کن (`base64 -w0 release.jks`) و در Settings ← Secrets این‌ها را بساز: `KEYSTORE_B64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`.
**فایل jks و رمزش را جایی عمومی آپلود نکن.**

## کم کردن حجم APK
حجم فعلی احتمالاً بین ۱۰ تا ۲۰ مگابایت است. برای کمتر شدن، در `app/build.gradle.kts` مقدار `isMinifyEnabled` و `isShrinkResources` را `true` کن. اگر ساخت با خطای R8 شکست خورد، یعنی یک کلاس به قوانین `proguard-rules.pro` اضافه شود (متن خطا نام آن را می‌گوید)؛ در این صورت دوباره به `false` برگردان.

## نگهداری
یوتیوب گاهی روش‌هایش را عوض می‌کند و دانلود از کار می‌افتد. راه‌حل: در `app/build.gradle.kts` نسخه `NewPipeExtractor` را به آخرین نسخه در
https://github.com/TeamNewPipe/NewPipeExtractor/releases تغییر بده، دوباره بساز و APK جدید را جایگزین کن.

## نکات حقوقی
دانلود از یوتیوب خلاف شرایط استفاده آن است و بیشتر ویدیوها حق کپی‌رایت دارند. برای استفاده شخصی ریسکش کم است، ولی انتشار عمومی مسئولیت خودت است. گوگل پلی چنین برنامه‌ای را نمی‌پذیرد؛ فقط از طریق دانلود مستقیم APK پخش می‌شود.
